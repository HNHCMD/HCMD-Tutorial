# Environment Setup (macOS)

Minimal commands for macOS users who want to run the code used in HCMD tutorials.

## .NET 8 SDK
Install via Homebrew:
```
brew install --cask dotnet-sdk
```

Verify installation:
```
dotnet --version
```

## Optional: Java
Install a standard JDK:
```
brew install --cask temurin
```

Verify:
```
java -version
```

## Optional: Editors
Any editor is acceptable (e.g., VS Code, Visual Studio for Mac).
