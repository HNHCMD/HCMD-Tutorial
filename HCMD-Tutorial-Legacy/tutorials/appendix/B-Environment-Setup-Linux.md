# Environment Setup (Linux)

Minimal commands for Linux users who want to run the code used in HCMD tutorials.

## .NET 8 SDK
Install .NET 8 using your distribution’s package manager or Microsoft’s packages:
https://learn.microsoft.com/dotnet/core/install/linux

Verify installation:
```
dotnet --version
```

## Optional: Java
Install a standard JDK:
```
sudo apt install default-jdk
```
or your distribution’s equivalent.

Verify:
```
java -version
```

## Optional: Editors
Any editor is acceptable (e.g., VS Code, Vim, Emacs).
