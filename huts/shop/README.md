# HutShop

The HutShop contains the official, public-ready huts of HCMD.  
Only huts that have reached conceptual stability, reproducibility, and clear definition are placed here.

A hut in the HutShop is:

- structurally complete  
- paired with a canonical blueprint  
- reproducible across sessions  
- aligned with HCMD principles  
- suitable for public documentation and teaching  

The HutShop is the “major league” of huts:  
artifacts here represent the stable cognitive modes of the HCMD discipline.

## Contents

Each hut in this directory appears as a pair:

- `<Name>_Hut.md` — the cognitive stance  
- `<Name>_Blueprint.md` — the canonical definition and recovery document  

In addition, the HutShop may contain optional constraint modules that refine how huts are applied in practice.

## Style Constraint Module

- **HCMD-Style-Constraints.md**  
  Defines optional document‑style rules (such as ATX‑only headings) that may be activated alongside a hut.  
  These constraints govern formatting, not reasoning, and help maintain consistency across HCMD documents.  
  The module is independent of the HCMD Hut and can be used whenever a stable formatting standard is required.

## Promotion Criteria

A hut is included in the HutShop when it satisfies all of the following:

1. **Purpose Clarity**  
   The hut’s role is unambiguous and consistently applicable.

2. **Boundary Definition**  
   The hut clearly states what it includes and excludes.

3. **Reproducibility**  
   The stance can be restored using its blueprint alone.

4. **Stability**  
   The hut no longer changes under normal use.

5. **Alignment with HCMD**  
   The hut supports the HCMD loop and respects layer boundaries.

## Current Official Huts

- **HCMD Blueprint**
