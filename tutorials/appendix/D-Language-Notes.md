# Language Notes

These notes explain the minimal language context for HCMD tutorials.

## C# as the Primary Implementation
C# is used as the primary implementation language because:

- it provides a clear, strongly typed structure
- it exposes the shape of the STS cleanly
- it avoids language-specific shortcuts
- it is stable and reproducible across platforms

## Java as an Optional Secondary Implementation
Java is included optionally to show:

- how the same structure appears in a different language
- how HCMD avoids language-specific tricks
- how cross-language implementations reveal structural invariants

Java is not required to follow the tutorial.

## No Language-Specific Techniques
HCMD tutorials avoid:

- idioms
- shortcuts
- framework-specific features

The goal is to expose structure, not language expertise.
