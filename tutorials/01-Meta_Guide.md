
**01‑Meta Guide — The Taxi Problem**
====================================

The first tutorial is still extremely simple.

Imagine this:  
You take a taxi from an airport to your friend’s house, but you’ve forgotten the address.  
Fortunately, you’ve driven there many times before.  
So you begin giving the driver detailed instructions:

* turn left at the big intersection
* go straight until the gas station
* take the second right
* avoid the road with construction

It works, but only because you remember the route.

Setting up something new on a computer often feels the same.  
If you follow a long, step‑by‑step guide, you might get there.  
But sometimes:

* the system updated
* the package version changed
* the directory moved

And suddenly the instructions no longer work.

Now consider a different situation.  
You’re going to a hotel.  
You don’t give the driver a list of turns.  
You simply say:

> “The Grand Hotel, please.”

And the driver takes you there.

Computers can be like that too.  
If you’re doing something ordinary, you don’t always need the full map.  
You can simply ask a chat assistant what you want to do, instead of digging through manuals.

And your favorite chat will be sufficient for most cases.  
In fact, we usually ask chat before searching for information explicitly.

Let us try a slightly realistic example.  
Suppose we want to prepare the dataset of the California Housing Price in CSV format so that we can use it in later exercises.

Please try the following query by yourself, in your own style:

> **“prepare the California housing dataset”**

We will discuss it in the next tutorial.

And if you feel that this is _too_ simple — that feeling is intentional.
